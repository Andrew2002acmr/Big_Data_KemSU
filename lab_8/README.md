# Лабораторная работа № 8

**Вариант 6**. Страхование, прогноз страхового случая. Сценарий — открытая публикация учебного датасета.

## Запуск

Windows PowerShell, Python 3.12 x64. Запустите из каталога `lab_8`:

```powershell
.\run_lab.ps1
```

Скрипт создаёт четыре виртуальных окружения с закреплёнными версиями пакетов и запускает все шесть этапов на CPU. Установка зависимостей требует интернета. MOSTLY AI работает локально, через loopback. Результаты прогона сохраняются в `tmp/results/`; сгенерированные строки и модели остаются в `tmp/`. Полный прогон может занять несколько минут.

- `./run_lab.ps1 -Notebook` открывает ноутбук в JupyterLab. Выберите **Run All Cells** для нового прогона.
- `./run_lab.ps1 -Reuse` использует сохранённые локальные этапы. Для чистого эксперимента используйте команду выше без флагов.
